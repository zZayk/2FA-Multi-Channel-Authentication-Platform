📖 Glossary

Quick definitions for the jargon scattered through the codebase.

TermIn one line
OTPOne-Time Password — short code valid once, briefly.
HMACKeyed hash; proves a value without storing it, needs the secret key to forge.
DLRDelivery Receipt — carrier's confirmation an SMS arrived (Month 2).
BrokerThe queue (Redis) holding jobs between API and worker.
Celery workerProcess that runs queued jobs (sending messages).
Celery BeatScheduler that enqueues periodic jobs (cron-like).
AdapterClass wrapping one external channel behind a shared interface.
correlation_idTrace UUID following one request across services + logs.
IdempotentSafe to run twice with the same effect as once (dispatch skips non-pending).
LifespanFastAPI startup/shutdown hook for shared resources.
MigrationVersioned, reversible schema change (Alembic).
DriftWhen models and migrations disagree — the drift test catches it.
Dependency overrideSwapping a real Depends for a stub in tests.
Transient errorTemporary failure worth retrying (timeout, 5xx).
Permanent errorWon't fix itself; don't retry (bad recipient, 401).
SecretStrPydantic type that hides secrets from logs/repr.
E.164International phone format: + then up to 15 digits.
CSPRNGCryptographically secure RNG (Python secrets) — unpredictable.
