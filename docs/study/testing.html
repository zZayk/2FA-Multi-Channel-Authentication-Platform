🧪 Testing

Four layers of tests. Fast ones run anywhere; heavy ones spin a real Postgres on demand.

flowchart LR U["Unit hash, code gen"] --> S["Schema + Auth 401, 422"] S --> I["DB Integration full lifecycle"] I --> E["E2E request to verify"] E --> D["Drift migrations == models"]

Run them

# fast tests — no Docker daemon needed
docker compose run --rm api pytest -q

# everything, incl. a real Postgres via testcontainers
docker compose run --rm api pytest -q --run-integration

# one test class
docker compose run --rm api pytest -q tests/test_otp_service.py::TestHmacRoundtrip

# lint
docker compose run --rm api ruff check app tests
Why two modes? CI and quick local loops shouldn't need Docker-in-Docker. Integration tests opt-in with --run-integration so the default run stays fast and green.

Hands-on end-to-end (see it actually work)

1 · BOOT

cp .env.example .env          # set SECRET_KEY
docker compose up --build -d
docker compose run --rm api alembic upgrade head

2 · MINT AN API KEY (shown once — copy it)

docker compose run --rm api python -c "
import asyncio
from app.core.database import SessionLocal
from app.services import api_key_service
async def main():
    async with SessionLocal() as s:
        _, pt = await api_key_service.create_api_key(s, name='dev-local')
        print('API KEY:', pt)
asyncio.run(main())"

3 · REQUEST AN OTP

curl -i -X POST http://localhost:8000/otp/request `
  -H "Content-Type: application/json" `
  -H "X-API-Key: l2t_PASTE_KEY_HERE" `
  -d '{\"channel\":\"sms\",\"recipient\":\"+21620000000\"}'

4 · READ THE CODE FROM WORKER LOGS (no real gateway in dev)

docker compose logs worker | Select-String "dispatch"

5 · VERIFY IT

curl -i -X POST http://localhost:8000/otp/verify `
  -H "Content-Type: application/json" `
  -H "X-API-Key: l2t_PASTE_KEY_HERE" `
  -d '{\"recipient\":\"+21620000000\",\"code\":\"418207\"}'
The HTTP response never carries the code (by design). In dev with no real gateway the send "fails", but the row + flow are real. Add MailHog (see Observe) to actually see Email codes in a UI.
The commands use PowerShell syntax (backtick line-continuation, Select-String) since you're on Windows. In Git Bash, swap ` for \ and Select-String for grep.
